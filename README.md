# MetaCode · 私信聚合客户端（dc-dm）

> Windows 桌面客户端，配合 [MetaCode 网站](https://metacode.top/data/discord) 使用：把你账号库里多个 Discord 账号的私信汇总到一个窗口，有新私信、好友通过请求时第一时间提醒你。
>
> *English: a Windows desktop client for [MetaCode](https://metacode.top/data/discord). It aggregates the direct messages of many Discord accounts into one window and notifies you of new messages and accepted friend requests. Read-only: it never sends messages for you. Download the `.exe` from [Releases](../../releases).*

本仓库只发布打包好的程序，不包含源码。

## 下载

到 [**Releases**](../../releases) 页面，下载最新版本里的 `.exe` 文件，双击即可运行，无需安装 Python。

## 功能

- **多账号私信汇总**：所有账号的私信会话合并在一个列表里，按最近消息排序，带未读数，支持搜索。
- **账号状态一目了然**：在线 / 重连中 / 异常，点一下就只看这一类，账号很多时也好找。
- **聊天记录只读查看**：图片、贴纸直接显示。客户端**不会替你发送任何消息**。
- **新消息和好友通过提醒**：窗口标题未读数、任务栏闪烁、提示音，另有「通知」列表，点一条直接定位到对应好友。
- **去 Discord 回复**：一键用对应账号打开 Discord 官方客户端，并进入这个私信。
- **Webhook 推送（可选）**：把新私信和好友通过推送到你自己的 Discord 频道。

## 运行条件

- Windows 10 / 11，能正常访问 Discord
- MetaCode 网站账号（钱包）已被开通「Discord 自动化」权限，没有开通请联系我们
- 网站「账号库」里有要监控的账号，且账号**已启用并保存了登录凭证（token）**。没有凭证的账号不会出现在客户端里；用「加好友」客户端把账号登录运行一次，凭证会自动保存到网站
- 一个 **API Key**（在网站「API Key」里生成，只显示一次，请立即复制）
- 想用「去 Discord 回复」：电脑上安装 Discord 桌面版，且账号在网站上保存了邮箱和密码（开了两步验证的还要保存 2FA 密钥）

## 快速开始

1. 在 [网站](https://metacode.top/data/discord) 的「API Key」里点「生成新 Key」，复制保存。
2. 打开本客户端，粘贴 API Key，点「连接」。
3. 连接成功后账号会自动同步并开始监控，之后每隔几分钟自动同步一次。在网站上改了账号，也可以在客户端左下角「设置」里点「立即同步账号」。
4. 在左边选账号，中间选会话，右边查看聊天记录。需要回复时点右上角「去 Discord 回复」。

账号很多时，客户端会**按顺序逐个连接**，每个之间隔几秒，几百个账号全部连上大约需要二三十分钟，期间已连上的账号可以正常使用。
更详细的图文步骤见网站页面右上角的「私信聚合使用说明」。

## 设置 Webhook 推送

1. 在 Discord 频道的「设置 → 整合 → Webhook」里新建一个 Webhook，复制它的网址。
2. 在客户端左下角「设置」里找到「Webhook 推送」，粘贴网址，点「发送测试消息」确认连通，再点「保存」。
3. 之后新私信和好友通过都会推送到该频道，内容包含账号名和消息内容。

Webhook 网址相当于一把钥匙，谁拿到谁就能往你的频道发消息；推送的消息内容会发到那个频道，请确认只有你信任的人能看到它。

## 常见问题

**账号显示「异常」（红色）？**
多半是登录凭证（token）失效了。需要重新登录一次该账号并保存新的凭证，客户端下次同步时会自动拿到。

**一个 API Key 能在几台电脑上用？**
有数量上限，默认 1 台，可在网站「API Key」列表里看到「已绑定 / 上限」。需要更多请联系我们。同一个 Key 在多台电脑上监控同一批账号并且都开了 Webhook，会收到重复推送，建议只在一台电脑上开。

**提示「需要更新客户端」？**
版本过旧时服务器会拒绝连接，请到 Releases 下载最新版本。

**「去 Discord 回复」会怎样？**
会关闭你正在运行的 Discord，用这个账号重新打开官方客户端；每个账号第一次会自动登录，之后保留登录状态，同一时间只能打开一个账号。如果出现人机验证，请在 Discord 窗口里手动点一下。登录状态保存在客户端目录下的 `.discord_profiles` 文件夹，换电脑或交给别人之前请先删除。

**杀毒软件报毒 / Windows 提示「已保护你的电脑」？**
本程序是用 PyInstaller 打包的单文件程序，部分杀毒软件和 Windows SmartScreen 会误报。
请只从本仓库的 Releases 下载，核对 Release 说明里的 SHA-256 校验值；确认无误后可在杀毒软件中添加信任，SmartScreen 点「更多信息 → 仍要运行」。

## 注意事项

- 账号的登录凭证只保存在客户端的内存里，不写入本地文件；本地只保存 API Key 和你的设置。
- 长期挂着大量账号在线，本身有被 Discord 风控的风险，建议使用小号，账号数量循序渐进增加。
- 使用自动化工具可能违反 Discord 的服务条款，由此造成的账号限制或封禁，需要你自行承担。
